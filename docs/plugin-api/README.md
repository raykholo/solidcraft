# Plugin API reference

Generated by `cargo xtask plugin-api`. Do not edit these files by hand.

- [plugin.wit](plugin.wit): the component world, imports, exports and typed host errors,
copied from `crates/craft-plugin/wit/plugin.wit`. Generate Rust or TypeScript bindings from this file.
- [commands.json](commands.json): the engine command descriptions, input schemas and output schemas
returned by `engine.describe`, the same API served by MCP's `describe_command`.

A missing input or output schema means that command has not yet published that schema.
The host's command policy and the package's permissions determine which commands a plugin can run.

Run `cargo xtask plugin-api --check` to check freshness. The check regenerates the reference in memory
and fails if any generated file is missing, changed or unexpected.

See the [author guide](../plugin-guide.md) and [plugin skill](../../skills/solidcraft-plugins/SKILL.md).
